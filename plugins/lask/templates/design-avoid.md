# Design patterns to leave out

Hard constraints for any page, app UI, artifact, deck or component Claude designs.
Each line names a specific pattern; "avoid a generic look" only swaps one default for another.
The owner curates this list. Claude appends a line when the owner rejects a pattern, and
never deletes one.

- Cream, beige or off-white page backgrounds
- An italic or serif accent word inside an otherwise plain heading
- Numbered section labels such as "01 / 02 / 03"
- Small monospace or letter-spaced uppercase labels above headings
- Pill-shaped buttons
